# UI Review
1. Read `docs/design/design-system.md`, `docs/design/ui-assets.md`, and the active brief.
2. Review actual rendered pages if preview/browser tools are available; otherwise state limitations.
3. Check mobile/tablet/desktop layout, content overflow and Japanese typography.
4. Check focus states, keyboard access, contrast, labels, form errors and reduced motion.
5. Check token consistency, component reuse and per-asset licenses.
6. Classify findings by severity; provide file locations and actionable fixes.
7. Recheck fixes and explicitly report any tests not run.
