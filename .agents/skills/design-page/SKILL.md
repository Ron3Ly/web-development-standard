# Design Page
1. Read `AGENTS.md`, `docs/design/design-system.md`, `docs/design/ui-references.md`, `docs/design/ui-assets.md`, and the project brief.
2. State target users, goals, content, constraints and accessibility requirements.
3. Propose information hierarchy, page sections, reusable component inventory and responsive behavior.
4. Name the relevant design reference principles and asset candidates; flag license checks. Consider Astryx components/templates as an **optional** implementation candidate and consult `docs/design/astryx.md` before suggesting it.
5. Record assumptions, project-specific overrides and open questions.
6. Produce a concise design specification suitable for implementation.

Do not copy protected visual assets or adopt an unrelated technology stack.
