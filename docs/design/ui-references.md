# UI References

## Primary reference
- [Digital Agency Design System](https://design.digital.go.jp/dads/): usability, accessibility, form patterns, information architecture, components, typography and interaction guidance.
- [Digital Agency original design system page](https://www.digital.go.jp/policies/servicedesign/designsystem): source portal / background.

## How to use references
1. Identify the user task and the specific UI pattern to research.
2. Capture the *principle* being adopted, not an exact branded page or proprietary asset.
3. Prefer official design guidance and existing components over ad-hoc visual invention.
4. Record the source URL, screenshot date, component/pattern, rationale and accessibility implications.
5. Save screenshots only when permitted; a live URL may change over time.
