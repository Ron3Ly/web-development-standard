## 2. データフローと信頼境界

入力・出力、受信者、権限検証、ログ記録、キャッシュと保存期間をマッピング。

```text
[利用者のブラウザ / 未信頼]
      | HTTPS / Cookie / OAuth redirect
      v
[Cloudflare Workers: Vinext RSC + API + Server Actions]
      |-- 認証・オブジェクト認可 --> [D1 個人情報/権限]
      |-- 認証・オブジェクト認可 --> [R2 私有オブジェクト]
      |-- 許可された外部fetch ------> [Google / 音楽サービス API]
      |-- 実際の設定を確認 ----------> [ログ/アクセス解析]
[GitHub Actions / deploy] --> [Cloudflare環境 & secrets]
```

※ データフロー図は典型例。導入していないサービス・機能は削除し、実際の実装構成に合わせる。
